PROMPTVAULT / FIELD GUIDE

A better prompt.
Always within reach.

Your private library for the instructions worth keeping.

From idea to input in three steps

  1. Save something useful. Open the extension, choose + New, and give your prompt a title and body. Pick a collection if you like.
  2. Choose your destination. Click a text input or editor on an ordinary webpage.
  3. Bring your prompt along. Open PromptVault and choose Insert. Your prompt is appended to the existing text. Nothing is sent or submitted automatically.

The even faster route

Right-click an editable field → PromptVault · Insert prompt → choose a saved prompt. Favorites appear first. Menus update when you save, favorite, import, or delete prompts.

Save directly from a webpage

Select text and right-click → Save selection to PromptVault. To capture an entire editable field without selecting text, right-click inside it → Save field text to PromptVault. Chrome may group these items inside a PromptVault submenu. The prompt receives an automatic title and is saved to General. A page message and green SAV badge confirm saving; rename it later in the library if you like.

Blank text and prompts longer than 20,000 characters are rejected. Password and read-only fields cannot be captured with Save field text. Refresh pages after updating the extension.

A small library with useful habits

  • Search by words in the title, body, or collection. Press / to search.
  • Star your best prompts and filter by Favorites or collection.
  • Use Copy for editors that do not accept injection.
  • Export a JSON backup before changing browsers or removing the extension. Import merges prompts and skips identical title/body pairs.
  • In the editor, press Ctrl + Enter to save.

Private by design

Prompts are stored in chrome.storage.local on this browser profile. There are no accounts, analytics, external libraries, or network requests. Local storage is not encrypted by this extension. Uninstalling the extension removes its library.

The content script runs on HTTP and HTTPS pages to remember the focused or right-clicked field, including accessible frames. It changes the field only when you choose Insert or a menu item. Once inserted, the text belongs to the destination webpage and that site's data handling applies.

When a field will not cooperate

Chrome settings pages, the Chrome Web Store, PDF viewers, and other protected pages block injection. Password, disabled, and read-only fields are excluded. Closed shadow roots and some custom editors may not work; use Copy there. Pages opened before installation may need a refresh for the right-click target to be remembered. On right-click failure, a “!” appears on the extension icon; hover over it for the reason.

File URLs are not included. For the supplied practice page, start the local server in the README and visit the localhost address.
